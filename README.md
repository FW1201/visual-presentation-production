# Visual Presentation Production

以宿主原生繪圖能力製作完整 16:9 投影片的可攜 Agent Skill，支援 Codex 與 ChatGPT Work。

- Outline → style → sample → per-slide generation → QA → PNG／PDF／PPTX assembly。
- 支援講者稿、品牌輸入與可續作的視覺 style profile。
- 不使用圖像 API、API key、外部圖像 CLI 或程式繪製投影片。

請閱讀繁體中文 [使用說明.md](使用說明.md)。

ChatGPT Work 的安裝必須從個人頭像 → **Skills → New skill → Upload from your computer** 完成；將 ZIP 附在 Work 對話中只會作為參考檔案，不能要求對話代理代為安裝。
